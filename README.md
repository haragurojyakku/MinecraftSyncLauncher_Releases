# MinecraftSyncLauncher_Releases

This repository is a **distribution point only** — it exists so that
[GitHub Releases](https://github.com/haragurojyakku/MinecraftSyncLauncher_Releases/releases)
has somewhere to attach the launcher's built zip assets, and so the
launcher's in-app update checker (`UpdateChecker`, which only calls the
`releases/latest` GitHub API — it never reads this repository's file tree)
has tags to compare against.

It intentionally does **not** contain source code. Development happens in
a separate private repository. Download the latest build from the
[Releases page](https://github.com/haragurojyakku/MinecraftSyncLauncher_Releases/releases/latest).
